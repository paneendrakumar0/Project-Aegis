# Roadmap

## Phase 1: Credible Baseline

- Create the simulation package and scenario model.
- Implement decentralized threat scoring and intercept selection.
- Add stochastic batch evaluation.
- Add tests for threat scoring, attendance, and deterministic replay.
- Provide a browser visual demo.

## Phase 2: Technical Depth

- Add multi-asset scenarios.
- Model sensing range, classification uncertainty, and missed detections.
- Add communication-degraded modes.
- Add structured scenario configuration files.
- Export CSV and JSON reports for evaluation runs.

## Phase 3: Review-Ready Package

- Add architecture diagrams and evaluation report templates.
- Produce a recorded demo scenario.
- Create a BEL/DRDO-facing technical presentation.
- Add benchmark comparisons between baseline, greedy, and coordinated policies.

## Phase 4: Advanced Research

- Add auction-based distributed task allocation.
- Add receding-horizon intercept planning.
- Add adversary behavior models.
- Add reinforcement-learning experiments as a comparison track.
