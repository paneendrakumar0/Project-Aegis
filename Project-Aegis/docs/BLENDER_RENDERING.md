# Blender Rendering

## Purpose

Blender is the interim cinematic renderer for Project Aegis. It produces a
more serious 3D mission preview from the same telemetry used for metrics,
Gazebo scene export, and future ROS bag playback.

## Generate Render

```bash
make blender-render
```

Outputs:

- `assets/blender/aegis_blender_snapshot.png`
- `assets/blender/aegis_blender_mission.mp4`

The current committed render is 1280x720, 24 frames, and generated from
`scenarios/baseline_asset_defense.json`.

## Notes

- The renderer runs headless through `blender -b`.
- The scene is generated procedurally from JSONL telemetry.
- Drones, defended compound, protected asset, tactical ground, camera, and
  lighting are all generated by `tools/blender_mission_render.py`.
- This is still an interim render path. Gazebo/ROS validates engineering
  playback; Isaac Sim or Unreal Engine should carry the final stakeholder
  cinematic.
